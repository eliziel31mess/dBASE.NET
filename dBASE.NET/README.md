
# dBASE.NET

En esta versión se han agregado algunas funciones que se requieren para el uso de tablas DBF especificas, con esto podemos convertir los registros
a un listado del tipo `<Entity>` para poder trabajar con ellos de una manera mas sencilla y rapida.

Otro de los requisitos primordiales era poder leer los campos de tipo Blob como un arreglo de bytes, ya que usualmente se guardan fotos, imágenes, etc. en este tipo de campos.
